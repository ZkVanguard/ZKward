# Contributing

ZKward is public for verifiability and audit, not as an open-source community
project. External code contributions are not currently accepted.

## Security disclosures

See [`SECURITY.md`](./SECURITY.md) for the responsible-disclosure process.
Never open a public issue for an active vulnerability.

## Public issues

Reproducible non-security bugs on the public site, documentation errors, and
ecosystem-integration questions are welcome on GitHub. Search closed issues
first. Include:

- Clear description
- Reproduction steps
- Environment details (browser, wallet, chain)
- Screenshots or logs when relevant

## Everything else

Feature requests, roadmap suggestions, and general discussion belong in the
channels linked from the [README](../README.md).
